## Agent skills

### Issue tracker

Issues and specs live in [GitHub Issues](https://github.com/kevindb/jquery-load-json/issues) for `kevindb/jquery-load-json`; use the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Domain docs

Single-context: root `GLOSSARY.md` (when present) and `docs/adr/`. See `docs/agents/domain.md`.

### Coding standards

Read `docs/agents/coding-standards.md` when modifying source, tests, build/lint/format config, packaging/tooling, or commits. Conventional Commits (1–3 lines), BDD + AAA tests, edit `src/` never `dist/`; config wins once tooling lands.
