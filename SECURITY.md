# Security policy

## Supported versions

| Version              | Supported |
| -------------------- | --------- |
| 1.x (latest release) | Yes       |
| Earlier              | No        |

Fixes land on `main` and ship in the next release.

## Reporting a vulnerability

Please do not report security issues in public issues, pull requests or discussions.

Report them privately through GitHub: open the repository's **Security** tab and choose
**Report a vulnerability** (<https://github.com/kevindb/jquery-load-json/security/advisories/new>).

Include the plugin and jQuery versions, the data and markup used, and a minimal reproduction.
Reporters are credited in the advisory unless they ask not to be.
